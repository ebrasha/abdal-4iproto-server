# Reporting Issues

If you encounter any issues or have configuration problems, reach out via email at [Prof.Shafiei@Gmail.com](mailto:Prof.Shafiei@Gmail.com).

You can also report issues on GitHub:

- [abdal-4iproto-server](https://github.com/ebrasha/abdal-4iproto-server)

## Helpful Details to Include

- Operating system and architecture
- Install method (CLI or manual build)
- Relevant config snippets with secrets removed
- Exact error messages or log excerpts
- Steps to reproduce
