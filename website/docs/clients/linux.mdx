# Linux Client

Use the official desktop client for Linux.

## Download

[Download Abdal 4iProto Client for Linux](https://github.com/ebrasha/abdal-4iproto-client)

## Connection Checklist

- Server IP / hostname
- One of the ports from `server_config.json`
- Valid username and password from `users.json`
- Local SOCKS port if you plan to route application traffic

## Alternative

You may also use OpenSSH dynamic forwarding as described in [Connecting to the Server](../usage/connecting).
