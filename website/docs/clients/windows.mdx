# Windows Client

Use the official desktop client for Windows.

## Download

[Download Abdal 4iProto Client for Windows](https://github.com/ebrasha/abdal-4iproto-client)

## Recommended Workflow

1. Install the client
2. Enter server host, port, username, and password
3. Establish the tunnel
4. Point applications to the local SOCKS5 endpoint

See [SOCKS Proxy Usage](../usage/socks-proxy) for application configuration notes.
