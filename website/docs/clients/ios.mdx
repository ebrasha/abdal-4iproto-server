# iPhone (iOS) Client

On iOS, use a compatible SSH tunnel application with SOCKS5 support.

## Download

[Download SSH Tunnel with SOCKS5 Proxy from App Store](https://apps.apple.com/bw/app/ssh-vpn-port-forwarding/id6471132702)

## Connection Notes

- Use your Abdal 4iProto Server host and listening port
- Authenticate with a valid `users.json` account
- Enable dynamic / SOCKS forwarding in the app settings
- Route selected apps or system traffic according to the app's capabilities
