# Network Capabilities

Abdal 4iProto Server is built for practical tunneling workloads across common platforms.

## Multi-port Support

Run the server on multiple ports at the same time using the `ports` array in `server_config.json`.

## TCP Forwarding

Direct TCP connection forwarding is available without extra protocol gateways.

## UDP Forwarding

Full UDP traffic forwarding is supported for workloads that need more than TCP-only tunnels.

## Cross-platform

The server runs on both Linux and Windows.

## High Performance

Tuned for tunneling operations and documented as significantly faster than OpenSSH for this use case.

## DNSTT Support

Advanced DNS tunneling support is available for secure traffic routing scenarios where DNS-based transport is required.
