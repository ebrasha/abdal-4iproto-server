# Features Overview

Abdal 4iProto Server combines tunneling performance with operational controls that matter in real deployments.

## Capability Groups

- [Security Features](./security)
- [Traffic Monitoring](./traffic-monitoring)
- [Network Capabilities](./network)
- [Management Features](./management)
- [Accounting Features](./accounting)

## Highlights

- Built-in brute-force protection and attack logging
- Per-user traffic analytics and destination filtering
- Multi-port TCP/UDP tunneling with DNSTT support
- JSON-driven user/policy management
- Session limits, TTL, rate limiting, and traffic quotas

## Performance Note

The project is designed for high-performance tunneling and is documented as significantly faster than OpenSSH for tunneling-focused workloads.
